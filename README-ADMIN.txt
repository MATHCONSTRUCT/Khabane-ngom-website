KHABANE NGOM — ACADEMIC WEBSITE WITH ADMIN

This site is prepared for GitHub + Netlify + Decap CMS.

PUBLIC SITE
  The normal website is served from index.html.

ADMIN
  After deployment and authentication configuration, open:
  https://YOUR-DOMAIN/admin/

From the admin interface you can edit:
  - Homepage name, subtitle, introduction and hero image
  - Research text and topics
  - Publications
  - Teaching
  - Talks and conferences
  - CV PDF
  - Contact information

IMPORTANT
  Before activating /admin/, edit admin/config.yml and replace the GitHub repository placeholder with the real GitHub username/repository.

Verified public information already entered:
  - UCAD affiliation / number-theory area
  - Springer 2024 publication with Ismaila Diouf
  - Two publicly documented talks

Teaching, CV and private contact information are intentionally left for Khabane to add.
